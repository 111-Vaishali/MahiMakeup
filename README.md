# 💄 MAHI – Professional Makeup Artist Website  

A modern, elegant, and fully responsive portfolio website showcasing professional makeup services, client experiences, and seamless booking interaction.

---

## 🚀 Features  

### 🎠 Carousel  
Auto-playing image slider for showcasing work  

### 💍 Services  
Bridal • Party • Mehendi • Hair Styling • Pre-Maternity • Jewellery Rentals  

### 📅 Booking System  
Collects:
- Name  
- Phone  
- Service  
- Date  
- Location  

### 💬 Client Feedback  
Interactive feedback section with smooth animations  

### 👩‍🎨 About  
Professional introduction and service highlights  

### ❓ FAQ  
Quick answers to common queries  

### 📱 Responsive Design  
Optimized for mobile, tablet, and desktop
